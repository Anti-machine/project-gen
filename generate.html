Target structure

Bash script

Save this as setup.sh, make it executable with chmod +x setup.sh, then run it inside the directory you want to scaffold. 

#!/usr/bin/env bash

set -e

echo "Creating directories..."
mkdir -p src
mkdir -p assets/sound
mkdir -p assets/graphics

echo "Creating files..."
touch README.md LICENSE .gitignore

echo "Done. Structure created in: $(pwd)"
How it works Uses mkdir -p so it won't fail if parent folders already exist.
Safe reruns touch creates files if missing and updates timestamps if they already exist.
Run location matters The script creates everything in the current working directory, exactly as requested. 
chmod +x setup.sh
./setup.sh
